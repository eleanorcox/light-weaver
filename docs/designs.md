# Design gallery

Every design Light Weaver can weave, each as it looks on the loom. Choose one with the address shown, or play them all in turn with no address at all.

Screenshots are taken by `npm run screenshots` (all of them) or `npm run screenshots <name>` (one). A test fails if a design has no screenshot here, so every new design gets one.

## Kasuri, in the tradition of Kurume

`?scene=kasuri`

Warp and weft are tied and dyed with indigo before weaving, so the pattern forms with soft edges as the threads meet. The motif is our own, not a traditional one. Sources and credits: [research/elsewhere.md](research/elsewhere.md#kasuri-in-the-tradition-of-kurume).

![Kasuri](designs/kasuri.png)
